# Uroo UI — Examples

Kumpulan contoh siap pakai. Setiap contoh menggabungkan banyak komponen Uroo UI menjadi satu halaman utuh.

| Contoh | File | Deskripsi |
|--------|------|-----------|
| Dashboard Showcase | `examples/dashboard-showcase.html` | Gabungan KPI, charts, tabel, activity, kanban |
| Auth Flow | `examples/auth-flow.html` | Login → OTP → 2FA dalam satu halaman bertab |
| Ecommerce Storefront | `examples/ecommerce-storefront.html` | Navbar + produk grid + cart drawer |

Contoh lain dapat dibuka langsung dari folder `pages/` dan `modules/`.

Kembali ke hub: `../index.html`
