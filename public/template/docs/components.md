# Uroo UI — Komponen

Semua komponen berdiri sendiri (standalone), menggunakan boilerplate plus shared `../../assets/css/uroo.css`, dan memiliki tema gelap/terang + interaktivitas. Setiap panel demo diberi tombol **Lihat Kode** untuk melihat & **Salin** HTML-nya (engine `assets/js/uroo-copy.js`).
