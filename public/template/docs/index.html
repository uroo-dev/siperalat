Uroo UI — Design System

Design system & UI library berbasis Monochromatic Liquid Glassmorphism. HTML5 + Tailwind CSS v3 + Lucide, sepenuhnya offline.

Buka Index Glass Engine

1. Stack

LapisanTeknologi
MarkupHTML5
StylingTailwind CSS v3 (lokal) + Custom CSS .glass-panel
IconsLucide (lokal) + lucide.createIcons()
FontInter / Plus Jakarta Sans (lokal)
KonsepMonochromatic Liquid Glassmorphism

100% offline — Tailwind, Lucide, font & gambar sudah lokal di assets/.

3. Penggunaan

Semua file standalone & siap dibuka langsung di browser. Pola boilerplate (contoh di kedalaman 2, prefix ../../assets/):

<!DOCTYPE html>
<html lang="id" class="dark">
<head>
  <script src="../../assets/js/tailwind.js"></script>
  <script src="../../assets/js/lucide.js"></script>
  <script>tailwind.config={darkMode:'class',theme:{extend:{colors:{glass:{...}}}}}</script>
  <link rel="stylesheet" href="../../assets/css/uroo.css">
</head>
<body class="min-h-screen font-sans antialiased text-zinc-800 dark:text-zinc-100">
  <!-- Konten -->
  <script>lucide.createIcons(); /* + toggleTheme() */</script>
</body>
</html>

Kelas .glass-panel = backdrop-filter: blur(20px) saturate(180%). Panggil toggleTheme() untuk beralih gelap/terang.
