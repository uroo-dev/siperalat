Uroo UI - Komponen

Textarea

Area teks multibaris dengan berbagai kondisi: label, status validasi, penghitung karakter, meluas otomatis, serta footer aksi.

Variasi - Default

Kotak dapat ditarik dari sudut kanan bawah (resize vertikal).

Variasi - Dengan label

Tulis maksimal dalam 3 kalimat agar mudah dibaca.

Variasi - Status error dan sukses

Alamat email tidak dikenali. Gunakan format nama@perusahaan.id.

Catatan tersimpan dan terverifikasi.

Variasi - Otomatis meluas

Coba tekan Enter beberapa kali untuk melihat kolom berkembang otomatis.

Variasi - Penghitung karakter

0 / 160

Bilah berubah menjadi peringatan saat mendekati batas 160 karakter.

Variasi - Nonaktif

Interaktif - Validasi ulasan

Ulasan yang baik memuat kendala, solusi, dan rekomendasi.

Variasi - Dengan footer aksi

0 karakter · 0 kata

Footer memperlihatkan ringkasan isi sekaligus menyediakan aksi utama dalam satu kotak.
