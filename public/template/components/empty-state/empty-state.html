Empty State

Tampilan ketika sebuah halaman atau daftar belum memiliki data. Berbagai variasi empty state ditampilkan dalam kartu kaca berikut.

Variasi - Dengan ikon

Kotak masuk kosong

Belum ada pesan masuk. Pesan dari rekan tim dan sistem akan tampil di sini.

Variasi - Ilustrasi

Belum ada proyek

Semua draf dan kolaborasi proyek Anda akan muncul di area ini setelah dibuat.

Variasi - Tombol aksi

Keranjang belanja masih kosong

Temukan produk dan layanan digital terbaik untuk mengisi keranjang Anda.

Variasi - Hanya teks

Tidak ada notifikasi

Aktivitas baru dari grup, pesan langsung, dan pembaruan sistem akan dicatat di panel ini.
