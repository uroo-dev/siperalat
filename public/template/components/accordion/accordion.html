Demo 01 - FAQ

Akordeon Tunggal

Klaim salah satu panel otomatis menutup yang lain

Uroo UI adalah sistem desain berbasis glassmorphism monokromatik yang dibangun di atas Tailwind CSS. Kami menyediakan komponen lengkap - dari tombol, kartu, hingga modul dashboard - yang siap dipakai pada produk Uroo Studio, Uroo Kit, dan Uroo Metrics.

Tentu. Lisensi MIT memperbolehkan penggunaan bebas untuk proyek internal maupun komersial, termasuk modifikasi komponen. Kredit tidak wajib, namun kami senang bila Uroo UI disebut di dokumentasi proyek Anda.

Klik tombol ikon matahari atau bulan di pojok kanan atas. Preferensi Anda disimpan di localStorage sehingga pilihan tema tetap diingat saat kembali mengunjungi halaman.

Komponen ditulis murni dengan HTML, CSS, dan JavaScript vanilla. Kompatibel dengan Tailwind CSS, serta mudah diadaptasi ke React, Vue, maupun Svelte melalui adaptor resmi Uroo.

Demo 02 - Panduan

Akordeon Banyak Panel

Beberapa panel dapat terbuka bersamaan

  • Salin folder komponen ke dalam proyek Anda
  • Impor uroo.css di halaman Anda
  • Panggil lucide.createIcons() setelah DOM siap

Seluruh token terpusat di assets/css/uroo.css. Ubah variabel seperti radius panel, warna primer, atau intensitas blur pada :root dan seluruh komponen akan menyesuaikan secara konsisten.

Setiap pemicu dilengkapi aria-expanded dan aria-controls. Navigasi keyboard penuh didukung untuk pengguna pembaca layar.

  • Efek blur tidak muncul - pastikan peramban mengaktifkan akselerasi grafis
  • Ikon tidak tampil - jalankan ulang lucide.createIcons() setelah konten dinamis dirender
  • Tema tidak tersimpan - periksa pengaturan cookie pada peramban

Demo 03 - Fitur

Dengan Ikon Penanda

Ikon di awal menandai kategori panel

Uroo UI v3.2 hadir Agustus 2026 dengan 40+ komponen baru, sistem token yang diperbarui, serta dukungan penuh untuk mode terang dan gelap di seluruh halaman dashboard.

Enkripsi end-to-end untuk data klien, autentikasi dua tahap default, serta audit log yang tersimpan hingga 12 bulan untuk setiap perubahan pada ruang kerja.

Seluruh animasi hanya menggunakan transform dan opacity, sehingga tetap berjalan pada 60 fps bahkan di perangkat kelas menengah.

Paket Uroo Pro berharga Rp149.000 per bulan per pengguna. Termasuk komponen premium, dukungan prioritas, dan akses awal ke rilis beta.
